ℹ️ Instructions

Comment utiliser:

  1. Cliquez sur "Démarrer"
  2. Autorisez l'accès au microphone
  3. Jouez une note sur votre piano
  4. Observez l'écart en cents
  5. Ajustez jusqu'à obtenir 0 cents

Code couleur:

  • ● Vert: < 5 cents (parfait)
  • ● Orange: < 15 cents (proche)
  • ● Rouge: > 15 cents (ajuster)

Calibration:

Le mode calibration vous permet de mesurer l'inharmonicité réelle de votre piano pour un accordage plus précis. Suivez les instructions à l'écran et jouez les notes demandées.
