## 🚨 Problème urgent ?

### Microphone ne fonctionne pas
- Vérifiez les permissions dans les paramètres système
- Assurez-vous que le microphone est branché
- [Solution détaillée dans QUICKSTART.md](QUICKSTART.md#-problèmes-courants)

### Erreur d'installation
```bash
pip install -r requirements.txt
```
Si ça ne marche pas :
- [Guide dépannage dans QUICKSTART.md](QUICKSTART.md#-problèmes-courants)

### Je veux utiliser mon téléphone
- ⚠️ L'app ne fonctionne PAS directement sur mobile
- [Solutions dans MOBILE_ACCESS.md](MOBILE_ACCESS.md)

## ⚡ Lancement ultra-rapide

**Si vous êtes pressé et savez ce que vous faites :**

```bash
# Installation
pip install -r requirements.txt

# Lancement
python main.py
```

**Ou utilisez les scripts automatiques :**
- **Linux/macOS** : `./launch.sh`
- **Windows** : Double-cliquez sur `launch.bat`

## 💡 Ce que vous devez savoir

### ✅ L'application fonctionne sur :
- Windows (7, 10, 11)
- macOS (10.14+)
- Linux (Ubuntu, Debian, Fedora, etc.)

### ❌ L'application NE fonctionne PAS sur :
- iPhone / iPad (iOS)
- Téléphones / Tablettes Android
- Navigateurs web

### 💻 → 📱 Solution pour mobile :
Utilisez un bureau à distance pour contrôler votre ordinateur depuis votre téléphone.
[Guide complet ici](MOBILE_ACCESS.md)
