🚀 UTILISATION RAPIDE
───────────────────────────────────────────────────────────────────────

1. SUR VOTRE ORDINATEUR:
   
   pip install -r requirements.txt
   python web_server.py
   
   (ou double-clic sur launch_web.bat/launch_web.sh)
   
   Le serveur affiche votre IP (ex: 192.168.1.100)

2. SUR VOTRE IPHONE 12:
   
   Safari → http://192.168.1.100:5000
   
   Autorisez le microphone quand demandé

3. ACCORDEZ:
   
   Cliquez "Démarrer" → Jouez une note → Ajustez !
