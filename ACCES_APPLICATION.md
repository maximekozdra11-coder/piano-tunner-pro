2. L'application s'ouvre dans votre navigateur
3. **Pour installer l'application :**

     - Appuyez sur le bouton de partage (⬆️)

     - Appuyez sur les 3 points (⋮)

4. L'application apparaît comme une vraie app sur votre écran !

## ✨ Fonctionnalités de l'Application

### Ce Que Vous Pouvez Faire

✅ **Mesurer l'inarmonicité** de votre piano (notes A0 à A7)  
✅ **Voir la courbe** d'inarmonicité calculée automatiquement  
✅ **Accorder chaque note** avec le curseur de cents précis  
✅ **Sauvegarder** plusieurs profils de piano  
✅ **Travailler hors ligne** après le premier chargement  
✅ **Installer** comme application mobile (PWA)

### Premiers Pas

1. **Première utilisation :**
   - Cliquez sur "Nouvelle Mesure Piano"
   - Suivez les instructions pour jouer A0, A1, A2... jusqu'à A7
   - L'application calcule automatiquement la courbe d'inarmonicité

2. **Accordage :**
   - Sélectionnez votre profil piano
   - Commencez l'accordage
   - Suivez le curseur de cents pour chaque note
   - Le curseur devient vert quand la note est juste

3. **Sauvegarde :**
   - Tous vos profils sont sauvegardés localement
   - Pas besoin de compte ou de connexion
   - Les données restent sur votre appareil

## 🆘 Dépannage

### L'application ne se charge pas
- Vérifiez votre connexion internet (première visite uniquement)
- Essayez en navigation privée
- Videz le cache du navigateur

### Le microphone ne fonctionne pas
- Autorisez l'accès au microphone dans les paramètres du navigateur
- Sur iOS : Paramètres → Safari → Microphone
- Sur Android : Paramètres → Applications → Chrome → Autorisations

### L'application est lente
- Fermez les autres onglets
- Assurez-vous d'avoir une bonne connexion (première visite)
- Essayez de rafraîchir la page

### Impossible d'installer sur l'écran d'accueil
- Assurez-vous d'utiliser un navigateur compatible (Safari sur iOS, Chrome sur Android)
- Suivez les instructions spécifiques à votre appareil ci-dessus
